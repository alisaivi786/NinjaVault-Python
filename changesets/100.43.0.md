# ninjavault-cdn 100.43.0

Date: 2026-11-05
Type: Minor

## Changes
- Tenant ids are always `str`: `FileObject.tenant_id`, `AccessContext.allowed_tenant_ids`, `FileListQuery.tenant_id`
  and the `tenant_id` argument of `upload()` (sync and async) are typed `str`.
- A tenant id the server sends as a number or numeric string stays text (`42` -> `"42"`); it is no longer turned
  into an `int`.
- `upload()` trims surrounding whitespace from `tenant_id`. An `int` is still accepted at runtime for callers
  written against older versions, but the documented type is `str`.
- README examples use GUID tenant ids.

## Why
- The NinjaVault CDN server switched tenant ids from numeric ids to GUIDs. One type (`str`) for every tenant id
  matches the server and the .NET (`NinjaVault.Cdn`) and Node.js (`@ninjavault/cdn`) 100.43.0 packages.

## Breaking Changes
- Code that compared tenant ids read from the API with `int` values (for example `file.tenant_id == 42`) must
  compare with strings (`file.tenant_id == "42"`).
